## Evaluation
To evaluate the agent, you can use the ADK web interface to record evaluation sets.
- Create your evaluation sets.
- Place the evaluation set in ```tests/integration``` along with the basic test that is present.
  It will auto-discover tests that end with ```.evalset.json``` and that match the ADK evalset schema.
- ADK Eval docs: https://google.github.io/adk-docs/evaluate/
